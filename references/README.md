# references

Links to external resources used in this project. No need to clone them — they're just here for reference.

## KiCad libraries

- **Espressif KiCad Libraries** (official symbols, footprints, 3D models for ESP32 modules):
  https://github.com/espressif/kicad-libraries

## reference firmware

- **ESP32S3_PrintServer** — proof-of-concept ESP32-S3 WiFi-to-USB print bridge:
  https://github.com/MAXXTANG/ESP32S3_PrintServer

- **EspUsbHost** — Arduino library for USB Host on ESP32-S3:
  https://github.com/tanakamasayuki/EspUsbHost

- **esp32-zp450-print-server** — ESP32-S3 print server for label printers:
  https://github.com/mckinlk/esp32-zp450-print-server
